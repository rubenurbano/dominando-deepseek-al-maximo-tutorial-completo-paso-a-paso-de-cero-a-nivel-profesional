2. Fundamentos del Ecosistema DeepSeek y Mapa de Modelos

¿QUÉ ES DEEPSEEK?

Una empresa tecnológica china fundada en 2023 en Hangzhou (a menudo transcrita por error en subtítulos automáticos como Hano) y liderada por Liang Wenfeng (transcrito a veces como Lian Wenfen), ingeniero vinculado previamente al fondo de inversión cuantitativo High-Flyer.

¿PARA QUÉ SIRVE SU ARQUITECTURA?

Para ofrecer inteligencia artificial general de primer nivel mundial con un coste de entrenamiento y operación drásticamente menor gracias a su diseño de Mezcla de Expertos (MoE) y compresión de memoria intermedia (caché KV).

¿POR QUÉ CAMBIÓ EL MERCADO?

En enero de 2025, el lanzamiento de DeepSeek-R1 igualó o superó a los modelos propietarios estadounidenses en lógica, matemáticas y código con una fracción del coste, provocando un impacto bursátil histórico y abriendo la era de los agentes de pesos abiertos.

2.1. Qué es el código abierto (pesos abiertos) y cómo se sostiene su modelo gratuito y económico

Cuando un laboratorio publica un modelo de pesos abiertos (frecuentemente llamado código abierto bajo licencias permisivas como la licencia MIT), significa que no esconde la «receta matemática» entrenada dentro de servidores privados. Cualquier persona o empresa puede descargar esos archivos (llamados pesos), estudiarlos, modificarlos y ejecutarlos en sus propios ordenadores sin pagar licencias por usuario.

¿Cómo logra DeepSeek ofrecer chat gratuito sin suscripción, tarifas de API mínimas y modelos descargables gratis? Gracias a tres pilares documentados oficialmente:

  1. Eficiencia de arquitectura MoE (Mixture of Experts): sus modelos recientes son enormes en conocimiento total, pero solo activan una fracción pequeña de sus parámetros para procesar cada palabra o imagen (por ejemplo, en DeepSeek-V4.1-Flash hay 552B totales, pero solo se activan 8B en entrada y 16B en salida).
  2. Compresión extrema de memoria (Caché KV): reduce drásticamente el consumo de memoria intermedia (a un cuarto de HBM y un octavo de SSD respecto a la generación anterior), abaratando el coste de conversaciones largas y sesiones agénticas.
  3. Mejora continua por comunidad abierta: al liberar los modelos y DeepSeek Harness bajo licencia MIT, miles de desarrolladores crean optimizaciones, conectores y plugins que fortalecen todo el ecosistema.

2.2. Conceptos base imprescindibles antes de empezar

  • Parámetro (B = miles de millones): cada uno de los valores numéricos internos que la red neuronal ajustó durante su entrenamiento. Cuantos más miles de millones de parámetros tiene un modelo, mayor capacidad suele tener, aunque exige más memoria RAM/VRAM.
  • Token: unidad mínima de texto que procesa la IA (aproximadamente tres cuartos de una palabra en inglés o algo menos de una palabra en español, incluyendo signos de puntuación).
  • Ventana de contexto de 1M: significa que el modelo puede mantener presentes hasta un millón de tokens simultáneos entre tus instrucciones, archivos adjuntos y su respuesta, con hasta 384K tokens de salida máxima.

4. Nivel Intermedio: DeepSeek Harness (dsh) en Escritorio y Navegador

¿QUÉ ES UN HARNESS?

Un modelo de IA suelto es como un motor potente sobre una mesa: responde si le hablas, pero no tiene manos para leer carpetas ni crear archivos. Un harness (arnés o entorno agéntico) es la carrocería, el volante y las herramientas que convierten al modelo en un agente capaz de actuar.

ARQUITECTURA CORDIS

DeepSeek Harness (dsh) es de código abierto (licencia MIT, actualmente en public/developer preview) y se basa en el marco Cordis bajo la filosofía «todo es un plugin» (Everything is a Plugin): modelos, terminal, archivos e interfaz son módulos intercambiables.

COMPARATIVA DE ÉLITE

Compite directamente con Claude Code, Codex, OpenCode o Hermes, pero permite conectarle cualquier proveedor gratuito, API económica o modelo local de Ollama y reprogramar la propia aplicación desde el chat.

4.5. Los Cuatro Niveles de Permisos sobre tus Carpetas

  • 1. Solo lectura (Read-only): el agente lee archivos para informarse o resumir, pero tiene prohibido modificar, mover o borrar nada. Obligatorio al analizar documentos delicados.
  • 2. Ejecutar cambios (Ask / Approval): cada vez que el agente quiera crear, editar o borrar un archivo o lanzar un comando, se detiene y te muestra una tarjeta para aprobarlo clic a clic.
  • 3. Acceso completo (Full access / Write): el agente crea, edita y organiza archivos sin interrumpirte. Úsalo solo en carpetas de trabajo dedicadas o con copia de seguridad.
  • 4. Autoiteración (Beta): el agente ejecuta la tarea, se revisa a sí mismo, detecta mejoras o fallos y refina el resultado antes de entregártelo.

5. Nivel Avanzado: APIs Oficiales, Proveedores Gratuitos, Complementos y Modo Creador

5.1. Qué es una API y una API Key

Una API (Application Programming Interface) es un puente de comunicación directa entre programas para que DeepSeek Harness se conecte con los servidores del modelo. Una API Key es tu llave privada alfanumérica personal: nunca la compartas en capturas, vídeos ni repositorios públicos.

7. Nivel Profesional Avanzado: Modelos Comunitarios de Pesos Modificados y Privacidad Digital

7.1. Qué es la Abliteración (Eliminación de Rechazos en Pesos Abiertos)

Los modelos comerciales estándar incluyen filtros que a veces generan «falsos negativos» o rechazos automáticos ante consultas históricas legítimas, auditorías de tus propios sistemas o dudas médicas privadas. Es fundamental distinguir dos conceptos:

  • Trucos de prompt en modelos cerrados: intentar redactar juegos de rol para confundir a un chat en la nube. El modelo sigue intacto en el servidor.
  • Abliteración (Abliteration) en modelos de pesos abiertos: modificación matemática directa sobre los pesos internos de un modelo abierto para identificar y atenuar la dirección neuronal que dispara el rechazo automático, permitiendo responder consultas técnicas o académicas válidas sin bloqueos artificiales.

7.2. Cuatro Casos de Uso Legítimos y Responsables

1. INVESTIGACIÓN HISTÓRICA Y POLÍTICA

Analizar de forma objetiva conflictos históricos, geopolítica o debates académicos sensibles donde los chats comerciales devuelven negativas automáticas.

2. ARQUITECTURA DE SOFTWARE PROPIO

Estudiar cómo funciona internamente una aplicación propia o expresamente autorizada para aprender y diseñar alternativas limpias desde cero.

3. AUDITORÍA DEFENSIVA PROPIA

Revisar configuraciones, registros y posibles debilidades dentro de tus propios servidores y sistemas para endurecer su seguridad.

4. CONSULTAS PRIVADAS Y SALUD OFFLINE

Analizar en local contratos confidenciales o preparar dudas médicas personales antes de acudir al especialista sin que ningún servidor externo almacene tus datos.

7.3. Nube Privada (Abliteration.ai) frente a Descarga Local en Hugging Face

  • En la nube privada (si tu PC tiene poca memoria): plataformas como Abliteration.ai (https://abliteration.ai/) permiten usar estos modelos vía API de pago por uso. (Nota de rigor documental: en la transcripción automática del vídeo se escucha un nombre transcrito fonéticamente como «Lúteos» junto a Abliteration; al no existir constancia documental de una web oficial llamada exactamente así, conviene contrastarlo en la descripción del vídeo original si se busca ese servicio adicional).
  • En local gratis desde Hugging Face (máxima privacidad): en https://huggingface.co/ la comunidad publica variantes listas para ejecutar localmente (en formato GGUF con LM Studio, Jan u Ollama), como el ejemplo citado en las fuentes: DeepSeek V4 Pro basado en Qwen 3.5 de 9B parámetros (9.000 millones de parámetros, ligero para equipos domésticos).

7.4. Higiene Digital Externa y Protección frente a Data Brokers (Incogni)

Aunque ejecutes IA local para no filtrar documentos nuevos, tus datos personales previos (teléfono, correo, dirección física) suelen circular entre cientos de intermediarios comerciales (data brokers), alimentando spam y fraudes telefónicos. El vídeo menciona como patrocinador a Incogni (https://incogni.com/), que automatiza solicitudes legales de borrado ante más de 420 intermediarios de datos. Como regla general de seguridad: jamás subas datos bancarios, contraseñas ni documentos identificables sensibles a chats gratuitos en la nube.

Nivel 1 5. ¿Por qué la aplicación móvil no sirve para organizar carpetas de mi ordenador?
Porque la app móvil funciona únicamente como chat conversacional en la nube. Para que DeepSeek pueda leer, organizar o crear archivos reales en tu equipo necesitas instalar DeepSeek Harness en tu ordenador.
Nivel 1 6. ¿Qué significa que DeepSeek sea de «código abierto» o «pesos abiertos»?
Significa que los archivos matemáticos del modelo (bajo licencias abiertas como MIT) no están encerrados en secreto: cualquier persona o empresa puede descargarlos, modificarlos, integrarlos en otras herramientas o ejecutarlos gratis en sus propios ordenadores.
Nivel 1 7. ¿Es obligatorio añadir saldo o dinero la primera vez que instalo DeepSeek Harness?
No. Aunque el asistente inicial pueda sugerir añadir algo de crédito, puedes omitir ese paso y conectar proveedores gratuitos de terceros o modelos locales descargados con Ollama.
Nivel 1 8. ¿Por qué no puedo escribir en el chat de DeepSeek Harness aunque ya lo haya instalado?
Porque antes de habilitar el cuadro de escritura es obligatorio seleccionar un Workspace (una carpeta concreta de tu ordenador). En cuanto elijas una carpeta de trabajo, el cuadro de chat se activará.
Nivel 1 9. ¿Qué es un «token» explicado de forma sencilla?
Es la unidad mínima de texto en la que la IA divide tus mensajes y sus respuestas (aproximadamente una palabra corta o fracción de palabra), y sirve tanto para medir cuánta información cabe en memoria como para calcular el coste en las APIs.
Nivel 1 10. ¿Qué hace exactamente el nivel de permiso «Solo lectura» en DeepSeek Harness?
Permite que el agente lea y consulte todos los archivos dentro de la carpeta seleccionada para responder tus preguntas o resumir información, pero bloquea cualquier intento de modificar, mover o crear archivos nuevos.
Nivel 1 11. ¿Para qué sirve el botón «Trayectoria» dentro de una sesión de DeepSeek Harness?
Muestra paso a paso toda la línea de tiempo interna de lo que hizo el agente: qué herramientas utilizó, qué archivos leyó, qué comandos ejecutó y en qué orden ocurrió cada acción.

Nivel 2 — Bloque Avanzado (Preguntas 12 a 22)

Nivel 2 12. ¿Cuál es la diferencia práctica entre usar el Chat Web gratuito y usar la API oficial de DeepSeek?
El Chat Web es gratuito pero manual en navegador; la API oficial (platform.deepseek.com) se paga por consumo de tokens (con tarifas muy bajas, desde centavos por millón de tokens) y sirve para conectar DeepSeek Harness o tus propios programas y automatizaciones sin límites de interfaz.
Nivel 2 13. ¿Cómo se distingue un horario Punta (Peak) de un horario Valle (Off-Peak) en la API oficial?
Las horas punta son de lunes a viernes entre 01:00–04:00 UTC y 06:00–10:00 UTC (salvo festivos en China). Todas las demás horas del día, los fines de semana completos y los festivos chinos operan en horario valle con un 50% de descuento sobre las tarifas punta.
Nivel 2 14. ¿Qué papel juega la caché KV en el ahorro de costes con DeepSeek-V4.1-Flash?
Los agentes leen repetidamente los mismos archivos y contextos. V4.1-Flash comprime su caché KV (a un cuarto de HBM y un octavo de SSD respecto a la generación previa) y cobra los aciertos de caché a solo $0.003 por millón de tokens en horario valle, reduciendo drásticamente el gasto de sesiones largas.
Nivel 2 15. ¿Qué significa la arquitectura «todo es un plugin» basada en Cordis dentro de DeepSeek Harness?
Significa que no es un programa rígido: los proveedores de modelos, las herramientas de archivos, los terminales, la interfaz visual e incluso el bucle de decisión del agente son módulos independientes que se pueden intercambiar, activar o ampliar mediante complementos.
Nivel 2 16. ¿En qué se diferencian los cuatro modos de trabajo: Estándar, PTC, Mínimo y Creador?
Estándar ofrece todas las herramientas habituales paso a paso; PTC deja que el modelo escriba código para ejecutar múltiples herramientas en lote (ahorrando tokens, aunque más propenso a fallos en modelos pequeños); Mínimo deja solo terminal y edición básica para medir rendimiento puro; y Creador sirve para programar e instalar nuevos plugins dentro del propio harness.
Nivel 2 17. ¿Cuándo conviene usar «Acceso completo» frente a «Ejecutar cambios» o «Autoiteración»?
Usa Ejecutar cambios cuando quieras aprobar manualmente cada modificación; usa Acceso completo solo dentro de carpetas de trabajo seguras donde confíes en que el agente trabaje sin interrupciones; y usa Autoiteración (Beta) cuando quieras que el agente revise y refine su propio resultado antes de entregártelo.
Nivel 2 18. ¿Cómo puedes usar modelos gratuitos como DeepSeek V4.1 Flash Free dentro de DeepSeek Harness?
Conectando proveedores externos que ofrecen cuotas gratuitas —como OpenCode (cuya versión deepseek-v4.1-flash-free cuenta con política de cero retención según su documentación), OpenRouter (filtrando por free) o Nvidia NIM— mediante la configuración de Modelos o instalando el complemento correspondiente desde GitHub.
Nivel 2 19. ¿Qué tipo de cosas puedes construir con el «Modo Creador» sin escribir el plugin a mano?
Desde contadores de tiempo por tarea y monitores de gasto de tokens/coste, hasta un temporizador Pomodoro flotante, aplicaciones interactivas en 3D o cambiar el diseño visual completo y el nombre de la aplicación.
Nivel 2 20. ¿Qué ocurre si ejecuto DeepSeek Harness desde terminal con npx @deepseek-ai/dsh web en lugar de la app de escritorio?
Requiere tener instalado Node.js (^22.19.0 o >=24.0.0) y levanta un servidor web local en el puerto 3080 para manejar exactamente la misma plataforma agéntica directamente desde tu navegador web.
Nivel 2 21. ¿Cómo puedes programar tareas recurrentes automáticas en DeepSeek Harness?
Activando el complemento de tareas programadas (Scheduled tasks / Automation) y pidiendo en lenguaje natural la frecuencia deseada (por ejemplo, generar un informe semanal todos los viernes a una hora fija).
Nivel 2 22. ¿Por qué el vídeo recomienda visitar una página comprobadora como CanIRun.ai antes de instalar modelos locales?
Porque analiza automáticamente la memoria RAM/VRAM y GPU de tu dispositivo para indicarte con precisión qué tamaño de modelo (7B, 8B, 14B, etc.) correrá fluido en tu equipo y cuál lo ralentizará o bloqueará.

Nivel 3 — Bloque PRO (Preguntas 23 a 33)

Nivel 3 23. ¿Por qué un ordenador doméstico con 18 GB de VRAM no puede ejecutar DeepSeek-V4.1-Flash (552B) de forma nativa en memoria?
Porque el modelo completo requiere cientos de gigabytes de memoria (alrededor de 500 GB incluso cuantizado en formatos GGUF avanzados). Por eso en equipos domésticos se utilizan modelos R1 destilados (1.5B a 14B) que sí caben cómodamente en 8 a 18 GB.
Nivel 3 24. ¿Cuál es el proceso exacto paso a paso para descargar y probar un modelo local con Ollama?
Primero instalas Ollama desde ollama.com, después ejecutas en terminal ollama pull deepseek-r1:8b (ajustando el tamaño a tu hardware) y finalmente verificas su respuesta offline enviándole una prueba como "Hola ¿cómo estás?" desde la app de Ollama o con ollama run deepseek-r1:8b.
Nivel 3 25. ¿Qué dos métodos existen para conectar Ollama dentro de DeepSeek Harness?
El método rápido por terminal usando ollama launch dsh (que guarda sus ajustes en ~/.ollama/launch/dsh/settings.yaml sin alterar tus ajustes globales) o el método gráfico añadiendo un proveedor personalizado llamado Ollama apuntando a la URL http://localhost:11434/v1.
Nivel 3 26. ¿Por qué aparece el error de falta de clave API en web_search cuando usas DeepSeek Harness con Ollama?
Porque el complemento de búsqueda web predeterminado de DeepSeek Harness consulta el servicio de DeepSeek si no se cambia. Si trabajas offline o con Ollama local, debes desactivar esa búsqueda web o utilizar ollama launch dsh conectado a tu sesión de Ollama (ollama signin) con un modelo compatible con herramientas.
Nivel 3 27. ¿En qué se diferencia la «abliteración» de un modelo frente a los trucos de prompt en modelos cerrados?
Los trucos de prompt intentan sortear un filtro manipulando el texto enviado en una conversación sin alterar el modelo; la abliteración modifica directamente los pesos matemáticos internos de un modelo abierto para reducir su tendencia a rechazar consultas válidas de manera permanente.
Nivel 3 28. ¿Qué diferencia hay entre ejecutar un modelo sin filtros restrictivos en Abliteration.ai y descargarlo de Hugging Face?
Abliteration.ai ejecuta el modelo en servidores privados en la nube (es de pago por uso, útil si no tienes hardware potente); descargar variantes comunitarias desde Hugging Face (como la variante DeepSeek V4 Pro basada en Qwen 3.5 de 9B) es gratuito, privado y 100% local si tu equipo soporta ese tamaño.
Nivel 3 29. ¿Qué cuatro usos legítimos justifican emplear modelos locales con menor restricción de filtros?
La investigación académica de temas históricos/políticos sensibles, el análisis de arquitectura de software propio o autorizado, la auditoría defensiva de seguridad en sistemas propios y las consultas confidenciales sobre salud o documentos privados sin enviar datos a terceros.
Nivel 3 30. ¿Cómo compatibiliza la API oficial de DeepSeek herramientas creadas originalmente para OpenAI o Anthropic?
Ofrece dos URLs base oficiales: https://api.deepseek.com (compatible con el SDK y formato de mensajes de OpenAI) y https://api.deepseek.com/anthropic (compatible con el formato de Anthropic/Claude), permitiendo migrar herramientas existentes cambiando solo la URL base, el nombre del modelo y la clave API.
Nivel 3 31. ¿Qué riesgos implica cambiar el modo Estándar a Acceso Completo en una carpeta personal importante?
El agente podrá crear, sobrescribir, mover o eliminar archivos y ejecutar comandos en esa carpeta sin pedirte confirmación previa en cada paso. Por ello debe usarse exclusivamente en carpetas de proyecto dedicadas o respaldadas con copias de seguridad / Git.
Nivel 3 32. ¿Qué alternativas existen a Ollama para ejecutar modelos locales en interfaz gráfica?
Las fuentes destacan Jan (jan.ai) y LM Studio (lmstudio.ai), dos aplicaciones gratuitas de escritorio que facilitan descargar modelos cuantizados desde Hugging Face, comprobar su consumo de memoria y levantar servidores locales compatibles.
Nivel 3 33. ¿Por qué la protección frente a data brokers (como Incogni) complementa la privacidad al trabajar con IA?
Porque aunque ejecutes modelos locales offline para no filtrar tus documentos a servidores de IA, tus datos personales previos (teléfono, correo, dirección) pueden estar circulando entre cientos de intermediarios comerciales en internet alimentando spam y fraudes, por lo que proteger ambos frentes garantiza una privacidad integral.

9. Solución de Problemas Frecuentes (Troubleshooting Paso a Paso)

Si encuentras algún bloqueo durante la práctica, localiza aquí el síntoma exacto y aplica la solución verificada:

9.1. Fallos en Chat Web y App Móvil

Síntoma 1: El Chat Web no muestra el botón Run tras generar código

Causa: El modelo dividió el código en tres bloques separados (uno para HTML, otro para CSS y otro para JS).
Solución: Escríbele en el chat: «Unifica todo el HTML, CSS y JavaScript en un único archivo autocontenido para poder ejecutarlo con el botón Run».

Síntoma 2: La aplicación móvil no transcribe el dictado por voz

Causa: Falta permiso de micrófono en el sistema operativo o soltaste el botón antes de hablar.
Solución: Ve a los Ajustes de privacidad de iOS o Android, concede permiso de Micrófono a la app DeepSeek y recuerda mantener pulsado el icono durante toda tu frase antes de soltarlo.

9.2. Fallos de Instalación, Bloqueo de Escritura y Modos en DeepSeek Harness

Síntoma 3: El cuadro de texto del chat aparece gris y no me deja escribir

Causa: No has seleccionado una carpeta de trabajo (Workspace).
Solución: Pulsa en Seleccionar Workspace en la barra superior o lateral y elige una carpeta de tu ordenador; el cuadro se desbloqueará de inmediato.

Síntoma 4: Error al ejecutar npx @deepseek-ai/dsh web en terminal

Causa: No tienes Node.js instalado o tu versión es antigua.
Solución: Comprueba tu versión con node -v. DeepSeek Harness exige Node.js ^22.19.0 o >=24.0.0. Instala una versión compatible desde nodejs.org, reinicia la terminal y vuelve a lanzar el comando.

Síntoma 5: El agente falla repetidamente al llamar herramientas en Modo PTC

Causa: El modo PTC agrupa llamadas mediante un script intermedio que puede fallar en modelos pequeños o gratuitos.
Solución: Cambia el selector a Modo Estándar, repite la petición y audita los pasos en el botón Trayectoria.

Síntoma 6: Un complemento recién instalado o actualizado no aparece

Solución: Al actualizar o reemplazar un paquete ya cargado en memoria en DeepSeek Harness, cierra por completo la aplicación y vuelve a abrirla para que recargue los módulos Cordis.

9.3. Fallos de APIs, Proveedores Gratuitos y Búsqueda Web con Ollama

Síntoma 7: Error de autenticación (401) o falta de saldo en la API oficial

Causa: Clave copiada con espacios extra o saldo agotado (recuerda que el Chat Web gratuito y la API en platform.deepseek.com son productos independientes).
Solución: Revisa tu saldo en https://platform.deepseek.com/ y genera una API Key limpia.

Síntoma 8: Límite alcanzado en proveedor gratuito (OpenCode / OpenRouter)

Solución: Los modelos free tienen límites de peticiones por minuto. Espera unos minutos o cambia en el selector a otro proveedor gratuito (Nvidia NIM) o a tu modelo local en Ollama.

Síntoma 9: Error de falta de clave API en web_search al usar Ollama

Causa: La herramienta de búsqueda web por defecto sigue intentando usar el buscador de DeepSeek.
Solución: Desactiva el plugin de búsqueda web de DeepSeek en Complementos si trabajas 100% offline, o inicia sesión en Ollama (ollama signin) si usas ollama launch dsh.

9.4. Fallos de Hardware, Lentitud y Puertos en Ejecución Local

Síntoma 10: El modelo local responde lentísimo o bloquea el ordenador

Causa: El modelo supera tu RAM/VRAM disponible.
Solución: Verifica tu equipo en https://canirun.ai/, borra el modelo pesado con ollama rm <modelo> y descarga uno más ligero como ollama pull deepseek-r1:1.5b o ollama pull deepseek-r1:7b.

Síntoma 11: DeepSeek Harness no detecta modelos al añadir Ollama como proveedor personalizado

Solución en 3 pasos: 1) Confirma que la app Ollama está abierta en segundo plano; 2) Verifica que la URL escrita sea exactamente http://localhost:11434/v1 (incluyendo /v1); 3) Ejecuta ollama list en terminal para confirmar que descargaste al menos un modelo.

Síntoma 12: Puerto 3080 ocupado al lanzar dsh web

Solución: Lanza la aplicación en otro puerto libre añadiendo --port 3081 (o ollama launch dsh -- --port 3081).
